# Example videos

No example media is bundled with this repository. The original Genjustsu project's demonstration clips and artwork were excluded from its MIT grant and are not redistributed here.

Add your own demonstration clips to this folder if you want them for docs. Then, in the README, link them relatively, for example:

```markdown
[![preview](examples/previews/my-clip.gif)](examples/my-clip.mp4)
```

Processing any example through hosted providers incurs their normal charges. Supply your own identity references and media when running the workflow; do not commit footage, music or likenesses you do not have the rights to redistribute.
